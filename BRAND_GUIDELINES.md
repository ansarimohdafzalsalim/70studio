# 70studio Brand Guidelines

70studio is a design and AI agency based in Mumbai, India. The brand should feel minimal, editorial, technical, and conversion-focused: sharp enough for product teams, refined enough for premium brands, and practical enough for founders who need launch-ready work.

## Brand Essence

**Positioning:** Design and AI agency for brands, websites, apps, dashboards, and intelligent product experiences.

**Core line:** Design that thinks. Brands that convert.

**Personality:** Modern, calm, precise, ambitious, useful.

**Tone of voice:** Direct and confident. Use short sentences, clear outcomes, and active language. Avoid hype, filler, and generic agency language.

Good examples:

- “Editorial websites with sharp structure, fast flows, and conversion clarity.”
- “We turn insight into scope, architecture, flows, and creative direction.”
- “A compact studio for ambitious digital work.”

Avoid:

- Overly playful copy
- Corporate buzzwords without meaning
- Long paragraphs where a clean headline and one supporting line would work

## Color System

The website uses a dark-first palette with a refined light mode.

### Primary Palette

| Token | Hex | Usage |
| --- | --- | --- |
| Deep Black | `#0A0A0A` | Dark mode page background |
| Surface Black | `#111111` | Cards, panels, modals |
| Off White | `#F5F5F0` | Primary text on dark |
| Electric Indigo | `#5C4EFF` | Brand accent, CTAs, active states |
| Warm Gray | `#888888` | Secondary text |

### Light Mode Palette

| Token | Value | Usage |
| --- | --- | --- |
| Warm Off White | `rgb(247 247 242)` | Light mode page background |
| Clean White | `#FFFFFF` | Light mode cards/surfaces |
| Near Black | `rgb(18 18 16)` | Light mode primary text |
| Soft Gray | `rgb(94 94 88)` | Light mode secondary text |

### Color Rules

- Use Electric Indigo sparingly for action, signal, and brand recognition.
- Keep most layouts monochrome with one accent moment per section.
- Avoid large purple gradients. The accent should feel intentional, not decorative.
- Borders should be subtle: `ink/10` or `white/10` style opacity.
- Dark mode is the primary identity. Light mode should feel editorial and soft, not stark white.

## Typography

### Headings

**Font:** Syne  
**Weights:** 700, 800  
**Use for:** Hero headlines, section titles, card titles, logo.

Heading style:

- Bold
- Tight but readable line-height
- No negative letter spacing
- Large scale for hero only

### Body

**Font:** Inter  
**Weights:** 400, 500, 600  
**Use for:** Paragraphs, labels, forms, navigation, admin UI.

Body style:

- Clear and functional
- Muted secondary copy
- Avoid long dense blocks

## Layout

The site layout should feel spacious but not empty.

Rules:

- Use generous whitespace around major sections.
- Keep content inside the shared `container-pad` width.
- Cards use small radius, usually `8px`.
- Avoid nested cards.
- Use full-width bands for major sections instead of decorative containers.
- Public pages should lead with the actual experience, not marketing filler.

## UI Components

### Buttons

Primary:

- Electric Indigo background
- White text
- Rounded full
- Hover should invert using main text/background colors

Secondary:

- Transparent or glass surface
- Thin border
- Text in main ink color
- Accent border/text on hover

### Cards

Cards should be minimal and structured.

Use:

- `bg-surface`
- Thin border
- 8px radius
- Subtle hover lift for interactive cards

Avoid:

- Heavy shadows on dark mode
- Colorful card backgrounds
- Oversized rounded corners

### Navigation

The navbar is fixed, minimal, and transparent until scroll.

Required items:

- Logo
- Services
- Work
- About
- Contact
- Theme toggle
- “Start a Project” CTA

Mobile uses a full-screen menu with large Syne links.

### Footer

The footer is a floating bar.

It should include:

- Logo
- Main navigation
- Social links
- “More” expandable details
- Newsletter signup
- Copyright: `© 2026 70studio · All rights reserved`

## Imagery

Image direction:

- Editorial, product-focused, architectural, and technical.
- Use real-feeling work previews, dashboards, interfaces, studio imagery, or AI/product visuals.
- Images should support the project story, not act as generic decoration.

Avoid:

- Generic smiling business stock photos
- Dark blurred abstract backgrounds where details cannot be seen
- Overly colorful images that fight the indigo accent

Project images:

- Use 16:10 ratio on cards.
- Use object-cover cropping.
- Add category badge on top-left.
- Hover may scale image slightly and reveal overlay.

## Motion

Motion should feel premium and quiet.

Current motion language:

- Word-by-word hero reveal
- Scroll-triggered fade and lift
- Parallax technical grid layers
- Subtle hover lift on cards
- Magnetic CTA behavior
- Marquee ticker for brand/client names
- Animated counters
- Custom cursor on desktop

Rules:

- Motion should clarify hierarchy or add polish.
- Keep durations smooth, usually `0.25s` to `0.7s`.
- Background animation must stay subtle.
- Respect reduced motion preferences.

## Admin Content Rules

Admin-editable content should preserve the same brand tone.

When adding projects:

- Use clear client names.
- Keep categories consistent.
- Add a concise but specific project description.
- Use strong images with visible subject matter.

When adding services:

- Keep descriptions short.
- Use deliverables that sound practical and concrete.
- Avoid duplicate service names.

When adding stories:

- Keep them minimal and founder/studio-focused.
- Prefer timeline-style entries over long essays.

## Do And Do Not

Do:

- Keep the interface sharp, restrained, and useful.
- Use indigo as a signal.
- Let type and spacing create the premium feel.
- Make admin content connect leads, clients, projects, services, and revenue clearly.

Do not:

- Add decorative blobs or random gradients.
- Overuse accent color.
- Use cartoonish icons or playful patterns.
- Make light mode pure white and harsh.
- Add marketing copy that sounds generic.
